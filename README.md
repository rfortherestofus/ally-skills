# ally-skills

Skills used in [Ally](https://rfortherestofus.com/ally) lessons and livestreams from R for the Rest of Us.

Install one into your project with the [{ally}](https://github.com/rfortherestofus/ally) package:

```r
pak::pak("rfortherestofus/ally")
ally::install_skill("rfortherestofus/ally-skills/r-data-tidying")
```

## Skills

- `r-data-tidying`: turn messy raw data (Excel, CSV, API dumps) into a set of tidy tables saved in `data-clean/`.
